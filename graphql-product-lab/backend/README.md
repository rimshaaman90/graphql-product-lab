
# GraphQL Product Management System

## Objective
A full-stack application using React, Node.js,
Express.js and GraphQL.

## Technologies Used
- React.js
- Node.js
- Express.js
- GraphQL
- graphql-request

## Features
1. Display all products.
2. Add new products.
3. Fetch products using GraphQL Query.
4. Add products using GraphQL Mutation.

## Backend
Runs on port 5000.

## Frontend
Runs on port 3000.

## How to Run

Backend:
cd backend
npm install
node index.js

Frontend:
cd frontend
npm install
npm start
